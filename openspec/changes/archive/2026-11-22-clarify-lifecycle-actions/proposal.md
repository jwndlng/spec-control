## Why

After a pull request opens, a stale retry flag can offer shipping again. While a session is running, the timeline can lose the recommended pull-request action and leave a button with only a chevron.

## What changes

Show a retry only after shipping fails before opening a pull request. Keep the next pull-request action visible while a session runs, and label menus that stand on their own.

## Impact

Lifecycle delivery records, the change detail timeline, shared action menus, Console pull-request actions, and Help.
