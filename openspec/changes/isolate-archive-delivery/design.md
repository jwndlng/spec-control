## Decisions

Use exact head branches and locally known pull requests to identify implementation delivery. Enforce the Archive prerequisite at the server entry points and show it beside the archive checkpoint. Keep the running agent and worktree available to complete implementation review. If the implementation session is still running after merge, offer to end it before starting the separate archive session.

Include the branch in the delivery response so the timeline can discard older archive records associated with implementation. Ignore a duplicate archive pull request number when a verified proposal or implementation PR owns it.
